# 💰 Анализ юнит-экономики сервиса «Всё.из.кафе»

## 📌 Описание проекта

Сервису доставки еды «Всё.из.кафе» предстоит запустить телевизионную рекламную кампанию. Для оптимизации бюджета необходимо оценить окупаемость привлечения новых пользователей в первые 7 дней жизненного цикла и выявить наиболее эффективные сегменты аудитории.

**Данные:**
- Когортный анализ пользователей (возраст, город, канал привлечения, тип устройства)
- Метрики: LTV, CAC, ROI
- Период: первые 7 дней жизненного цикла пользователя

---

## 🔧 Основные этапы работы

1. **Расчёт юнит-экономики:**
   - Расчёт LTV (выручка на пользователя) и CAC (стоимость привлечения).
   - Расчёт ROI (окупаемость инвестиций) в разрезе сегментов.
   - Анализ динамики LTV, CAC и ROI по дням.

2. **Сегментный анализ:**
   - Возрастные группы (18-25, 26-35, 35-50, 51-65, 65+).
   - Города (Саранск, Сочи, Мурино, Владивосток, Барнаул, Новосибирск).
   - Каналы привлечения (Source_A, Source_B, Source_C).
   - Типы устройств (Desktop, Mobile).

3. **Тепловые карты и визуализация:**
   - Тепловая карта LTV по сегментам.
   - Динамика ROI по сегментам.
   - Кривые окупаемости.

## 💡 Рекомендации

### 🎯 Ключевой портрет целевой аудитории
**Возраст:** 51-65 лет (и возможно 65+)  
**Устройство:** Desktop  
**Канал:** Source_B  
**Город:** Саранск  

**Потенциально перспективные сегменты:** Новосибирск, возраст 26-35 лет — мало клиентов, но высокий доход.

### 🚫 Сегменты для отключения
| Сегмент | Причина |
|---------|---------|
| Source_A, Source_C | Высокий CAC, невозможность окупаемости (40% клиентов) |
| Барнаул, Владивосток | LTV ≈ 0, высокая конкуренция |
| Возможно Мурино | Требует дополнительного исследования |

### 📺 Креативные рекомендации
- Для возрастной аудитории (51-65 лет) показывать, как сервис облегчает жизнь: возможность заказать любимые блюда без лишних усилий, через компьютер.
- Сюжет должен демонстрировать людей этого возраста, делающих заказ через десктоп.
