# 🐄 Отбор коров для молочного хозяйства

## 📌 Описание проекта

Фермер планирует расширить поголовье стада и хочет отбирать коров по двум критериям: годовой удой ≥ 6000 кг и "вкусное" молоко. На основе данных о текущем стаде необходимо построить две модели: регрессионную для прогнозирования удоя и классификационную для оценки вероятности получения вкусного молока.

**Данные:** 3 файла: `ferma_main.csv` (стадо), `ferma_dad.csv` (имена отцов), `cow_buy.csv` (коровы на продажу).

---

## 🔧 Предобработка данных

- Приведение типов, переименование столбцов.
- Удаление дубликатов и выбросов (аномально высокий удой).
- Приведение строковых признаков к нижнему регистру.
- Объединение таблиц по `id` для добавления имени отца.

---

## 🆕 Создание признаков

- Категориальные признаки закодированы через `OneHotEncoder`.
- Числовые признаки стандартизированы через `StandardScaler`.

---

## 📊 Ключевые результаты

- **Лучшая модель:** R² = 0.82, RMSE = 188.9
- **Ключевые факторы удоя:** ЭКЕ (сильная связь), сырой протеин, СПО.

### 🎯 Классификация (вкус молока)

- **Модель:** LogisticRegression
- **Базовый порог:** Precision = 0.60, Recall = 0.84
- **Оптимизированный порог:** 0.82 → Precision = 1.0 (снижение Recall до 0.03)

**Почему Precision критична:** Ошибка False Positive (прогноз "вкусное", а на самом деле нет) приводит к покупке неподходящей коровы и убыткам.

---

## 🐄 Отбор коров для покупки

Из кандидатов `cow_buy.csv` отобраны коровы, удовлетворяющие условиям:
- Прогнозируемый удой ≥ 6090 кг
- Вероятность "вкусного" молока ≥ 0.82 (оптимизированный порог)
