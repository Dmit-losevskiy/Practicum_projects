## 🚕 [Прогнозирование заказов такси](https://github.com/Dmit-losevskiy/Practicum_projects/tree/main/Taxi_orders_prediction%20)

**Стек:** `Python` · `Pandas` · `Scikit-learn` · `LightGBM` · `CatBoost` · `Statsmodels` · `Matplotlib` · `Seaborn`

**Задача:** Построить модель для прогнозирования количества заказов такси в аэропортах на следующий час на основе исторических данных (март – август 2018). Целевая метрика — RMSE ≤ 48.

**Результат:** Провёл исследовательский анализ временного ряда, создал временные и лаговые признаки, обучил и сравнил 4 модели. Лучший результат показала **LGBMRegressor** с RMSE на тесте **41.83**.

## 📺 [Онлайн-кинотеатр: дашборд активности пользователей](https://github.com/Dmit-losevskiy/Practicum_projects/tree/main/Online_cinema_user_activity_dashboard)

**Стек:** `Tableau Public`

**Задача:** Визуализировать ключевые метрики активности пользователей онлайн-кинотеатра — DAU, источники трафика, конверсии, время просмотра и топ фильмов.

**Результаты:**
- DAU стабилен (~6100), слабый нисходящий тренд.
- `organic` — лидер по привлечению новых пользователей (30%), `Mota` — аутсайдер (<5%).
- Конверсия в покупку: самая высокая у `IronSink` (6.9%), самая низкая у `organic` (2.2%).
- Новые пользователи – лишь часть всех активных.
- Средняя продолжительность просмотра на пользователя составляла от 2,2 до 2,7 часа
- Топ-3 по просмотрам: "Drishyam" (144), "Road to Perdition" (90), "Me and Earl and the Dying Girl" (89). Топ по рейтингу: "The Shawshank Redemption" (9.3), "The Godfather" (9.2), "The Godfather II" (9.0).

## 🏠 [Исследование рынка недвижимости Ленинградской области](https://github.com/Dmit-losevskiy/Practicum_projects/tree/main/Real_estate_data)

**Задача:** Проанализировать архив объявлений о продаже квартир в Санкт-Петербурге и области, выявить ключевые факторы, влияющие на стоимость недвижимости.

## 🐄 [Отбор коров для молочного хозяйства](https://github.com/Dmit-losevskiy/Practicum_projects/tree/main/Cow_project)

**Стек:** `Python` · `Pandas` · `NumPy` · `Scikit-learn` · `Matplotlib` · `Seaborn` · `SciPy`

**Задача:** Разработать две модели для отбора коров: регрессионную для прогнозирования годового удоя (цель — ≥ 6000 кг) и классификационную для оценки вероятности получения "вкусного" молока. На основе моделей отобрать коров, соответствующих обоим критериям.

**Результат:** Провёл предобработку и EDA данных о стаде, выявил корреляции (удой сильно связан с ЭКЕ), обучил 3 регрессионные модели (лучшая: R² = 0.82, RMSE = 188.88). Для классификации оптимизировал порог, максимизируя Precision (критична ошибка ложноположительного прогноза вкусного молока). Отобрал коров с удоем ≥ 6090 кг и максимальной вероятностью "вкусного" молока.
