**Задача:** Построить модель для прогнозирования количества заказов такси в аэропортах на следующий час на основе исторических данных (март – август 2018). Целевая метрика — RMSE ≤ 48.

## 🐄 [Отбор коров для молочного хозяйства](https://github.com/Dmit-losevskiy/Practicum_projects/tree/main/Cow_project)

**Стек:** `Python` · `Pandas` · `NumPy` · `Scikit-learn` · `Matplotlib` · `Seaborn` · `SciPy`

**Задача:** Разработать две модели для отбора коров: регрессионную для прогнозирования годового удоя (цель — ≥ 6000 кг) и классификационную для оценки вероятности получения "вкусного" молока. На основе моделей отобрать коров, соответствующих обоим критериям.

**Результат:** Провёл предобработку и EDA данных о стаде, выявил корреляции (удой сильно связан с ЭКЕ), обучил 3 регрессионные модели (лучшая: R² = 0.82, RMSE = 188.88). Для классификации оптимизировал порог, максимизируя Precision (критична ошибка ложноположительного прогноза вкусного молока). Отобрал коров с удоем ≥ 6090 кг и максимальной вероятностью "вкусного" молока.

## 🧩 Анализ поведения игроков в мобильной игре

**Стек:** `SQL` · `PostgreSQL`

**Задача:** Провести анализ поведения игроков игры-головоломки на основе событий из таблицы `puzzle.all_events`. Очистить данные, собрать их в 4 плоские временные таблицы (сессии, платежи, попытки, читеры), реализовать Last Click атрибуцию для каналов. Ответить на вопросы Product Owner: зависимость прохождения от скилла, выявление читеров, достаточность контента (1000 уровней) и анализ сложности (общей и чистой, без учёта покупок жизней и подсказок).

**Результат:** Подготовил ETL-процесс: развернул JSON-поля в колонки, реализовал Last Click атрибуцию для каналов, создал 4 временные таблицы. Выявил прямую зависимость между скиллом игрока и количеством уровней, пройденных с первой попытки (от 33.5 до 41.6). Обнаружил 1.37% читеров — терпимый уровень, требует мониторинга. Определил, что из 1000 уровней игроки прошли в среднем только 49, контента хватит минимум на 300 дней. Проанализировал общую и чистую сложность: чем выше уровень сложности, тем больше попыток требуется; использование бонусов снижает сложность незначительно (с 1.290 до 1.285 в среднем).
