# 📺 Анализ активности пользователей онлайн-кинотеатра

**Стек:** `Tableau Public` · `SQL` · `DAX` · `Data Visualization`

**Задача:** Разработать информационный дашборд для анализа активности пользователей онлайн-кинотеатра на основе предоставленных данных о DAU, источниках трафика, конверсиях, времени просмотра и популярности фильмов.

**Решение:** Создан дашборд в Tableau Public, включающий 6 визуализаций:
- Динамика DAU за период (линейный график)
- Привлечение новых пользователей с разбивкой по источникам (столбчатая диаграмма)
- Конверсия новых пользователей в покупку (вычисляемое поле)
- Доля активных пользователей по источникам
- Среднее время просмотра в день по источникам (в часах)
- Топ-50 фильмов по числу просмотров с рейтингом

**Результаты анализа:**
- **DAU** на уровне ~6100 пользователей в день с нисходящим трендом.
- **Источники трафика:** `organic` — лидер по привлечению новых пользователей (~30%), `Mota` — аутсайдер (<5%).
- **Конверсия в покупку:** самая высокая у `IronSink` (6.9%), самая низкая у `organic` (2.2%) — органические пользователи хуже конвертируются, несмотря на большой объём.
- **Новые пользователи** – лишь часть всех активных. Доля новых пользователей в общем числе активных различается: Organic – около 10%, Mota – ровно 50%.
- **Средняя продолжительность просмотра** на пользователя составляла от 2,2 до 2,7 часа, с пиковыми значениями 7 и 11 декабря.
- **Топ-3 фильма по просмотрам:** "Drishyam" (144 просмотра), "Road to Perdition" (90), "Me and Earl and the Dying Girl" (89).
- **Топ-3 по рейтингу:** "The Shawshank Redemption" (9.3), "The Godfather" (9.2), "The Godfather II" (9.0).

**Вывод:** Дашборд позволяет маркетологам и продуктовой команде быстро оценить эффективность каналов привлечения, выявить аутсайдеров и лидеров по конверсии, а также понять предпочтения аудитории в контенте.
