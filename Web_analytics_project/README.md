# 📈 Настройка веб-аналитики и управление рекламными кампаниями

## 📌 Описание проекта

Комплексная работа по настройке веб-аналитики для интернет-магазина: внедрение систем аналитики, настройка целей, анализ эффективности рекламных кампаний и оптимизация рекламного бюджета на основе данных.

**Данные:** 
- Счётчики Google Analytics и Яндекс Метрики
- Данные о рекламных кампаниях (расходы, показы, клики, конверсии)
- Отчёты по эффективности каналов и кампаний
- Данные о поведении пользователей на сайте

---

## 🔧 Основные этапы работы

1. **Настройка веб-аналитики:**
   - Установка счётчиков Google Analytics и Яндекс Метрики.
   - Настройка целей (воронка: просмотр → добавление в корзину → покупка).
   - Создание сквозной отчётности для оценки эффективности каналов.

2. **Анализ текущих рекламных кампаний:**
   - Оценка эффективности форматов объявлений (CTR, CR, CPA, CPO, ДРР).
   - Выявление точек роста и проблемных кампаний.

3. **Формулирование гипотез и оптимизация:**
   - Замена неэффективных креативов.
   - Обновление аудиторных сегментов.
   - Минусовка нерелевантных запросов.
   - Оптимизация посадочных страниц.

---

## 📊 Ключевые выводы анализа

### 🔍 Точки роста
- **Низкая конверсия (CR1)** формата “Сообщества (карусель)” — привлечение нерелевантной аудитории, выгорание сегмента.
- **Низкий CTR** формата “Ключевые фразы (запись с кнопкой)” — низкое качество креатива, отсутствие УТП.
- **Низкая конверсия в покупку (CR2)** у карусельных объявлений — возможные проблемы с наличием товара или несоответствие ожиданиям.

### 📉 Аномалии в отчётах
- **Максимальное снижение прибыли** — июнь 2022 года (падение на 324 тыс. руб.).
- **Ключевая проблема:** компания “Яндекс: Марочные — Поиск — Казань” — падение CR с 55% до 42%, CR1 до 2.42%, ДРР вырос до 72.6%.
- **Гипотеза:** региональные технические проблемы (оформление заказа, логистика) + дефицит ходовых товаров.

### 🎯 Рекомендации по оптимизации
| Проблема | Решение |
|----------|---------|
| Низкий CTR | Добавить УТП и ценовые офферы в заголовки |
| Высокий % отказов | Проверить соответствие посадочной страницы запросу, ускорить загрузку |
| Нерентабельные кампании | Минусовка нерелевантных запросов (капсбутик, nespresso аренда и др.) |
| Падение конверсии | Обновить выгоревшие сегменты, заменить креативы |
