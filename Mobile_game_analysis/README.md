## 🎮 [Анализ мобильной игры](https://github.com/Dmit-losevskiy/Practicum_projects/tree/main/Mobile_game_analytics)

### 📌 Описание проекта

Провести анализ выручки мобильной игры, выявить причины её снижения и предложить рекомендации по оптимизации монетизации и маркетинговых активностей. Необходимо построить дерево метрик, рассчитать ключевые показатели (выручка, DAU, ARPPU, конверсия, удержание) и определить проблемные сегменты.

**Данные:** 4 таблицы в БД PostgreSQL (проект `project`):
- `sessions` — сессии игроков (user_id, session_start_time)
- `transactions` — транзакции (transaction_id, user_id, event_date, product_id, product_name, revenue, quantity)
- `user_info` — информация об игроках (user_id, user_start_date, country, timezone, payer_segment, platform)
- `users_touches` — маркетинговые касания (user_id, touch_date, channel)

---

### 🔧 Основные этапы работы

1. **Подключение к базе данных и загрузка данных:**
   - Использован `psycopg2` для подключения к PostgreSQL.
   - Данные загружены через SQL-запросы в `pandas`.

2. **Расчёт дерева метрик (7 ключевых показателей):**
   - Daily Revenue (по продуктам и странам)
   - DAU (Daily Active Users) по каналам
   - ARPDAU (Average Revenue Per Daily Active User)
   - New Installs по каналам (Last Click Attribution)
   - Returning Users (Retention 1-day) по каналам
   - Daily Conversion по странам
   - ARPPU (Average Revenue Per Paying User) по сегментам плательщиков

3. **Визуализация и анализ динамики:**
   - Построение графиков в `plotly` для каждого показателя.
   - Выявление аномалий и точек падения.

4. **Дополнительные анализы:**
   - Удержание индийских игроков (weekly retention).
   - ARPU по когортам в Индии.

### 📊 Ключевые выводы

#### 🔍 Три основные причины снижения выручки

| Причина | Описание |
|---------|----------|
| **1. Отмена скидок** | После 23 октября 2023 прекратились продажи товаров со скидкой. ARPPU упал в 2-м и 3-м сегментах плательщиков — это малоплатящие пользователи, которые без скидок перестали покупать. |
| **2. Спад новых установок** | С начала октября 2023 снизилось привлечение новых пользователей через канал **Applovin**. New Installs упали, что привело к снижению общей выручки. |
| **3. Падение в Индии** | С начала декабря 2023 резкое падение выручки в Индии. Удержание игроков снизилось (Retention Rate последних когорт значительно ниже). ARPU также падает → игроки, остающиеся в игре, тратят меньше. |

#### 📈 Дополнительные наблюдения
- **Выручка по продуктам:** основной продукт — "Скидка" (до 23.10.2023), после отмены скидок выручка перераспределилась на другие продукты, но общая выручка упала.
- **Конверсия по каналам:** Applovin — ключевой канал привлечения, его спад критичен.
- **Индия:** падение удержания и ARPU требуют немедленного внимания.
