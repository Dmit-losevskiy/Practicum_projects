# 🛒 [Исследование интернет-магазина «В один клик»](https://github.com/Dmit-losevskiy/Practicum_projects/tree/main/Online_shop_analysis)

## 📌 Описание проекта

Интернет-магазин хочет персонализировать предложения для постоянных клиентов, чтобы увеличить их покупательскую активность. Необходимо разработать модель, прогнозирующую снижение активности клиента, и определить факторы, влияющие на это.

**Данные:** 4 таблицы:
- `market_file.csv` — поведенческие данные, коммуникации, продуктовые предпочтения (целевой признак — `Покупательская активность`).
- `market_money.csv` — выручка по периодам.
- `market_time.csv` — время на сайте по периодам.
- `money.csv` — среднемесячная прибыль.

---

## 🔧 Предобработка данных

- Приведение названий столбцов к нижнему регистру, замена длинных названий аббревиатурами.
- Проверка на пропуски и дубликаты (не обнаружены).
- Объединение таблиц по `id`.

---

## 📊 Исследовательский анализ данных

У покупателей с **прежним уровнем активности** выше:
- `актив_6_мес`, `просмотр_за_визит`, `страницы`, `выручка`, `минуты`

У покупателей со **сниженной активностью** выше:
- `акции`, `неоплачено_штук`

При снижении активности основными категориями становятся **товары для детей**, **косметика**, **домашний текстиль**.

## 📉 Корреляционный анализ

Обнаружена сильная корреляция между `выручка_тек` и `выручка_пред` → объединены в один признак.

- **ROC-AUC на тесте:** 0.9114

### 📊 Важность признаков (SHAP)

2. `минуты` — время на сайте
3. Остальные признаки — значимость распределена равномерно

## 🎯 Сегментация пользователей

**Характеристики покупателей со сниженной активностью:**
- `актив_6_мес` < 3 месяцев
- `акции` > 0.7
- `неоплачено_штук` ≥ 6
- `страницы` < 4
- `выручка_препред` < 4 400
- `минуты_пред` < 10
- `минуты_тек` < 10

**Основной сегмент:** покупатели с низкой выручкой (< 4 400).

**Поведение:**
- Часто покупают **товары для детей** по акциям.
- Почти не просматривают другие категории и страницы.
- Проводят минимум времени на сайте.

**Интересный факт:** пользователи со сниженной активностью приносят **больше прибыли** в категории детских товаров, чем пользователи с прежним уровнем активности.
