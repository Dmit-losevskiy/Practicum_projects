# 🍽️ Исследование точек роста в сервисе «Всё.из.кафе»

## 📌 Описание проекта

В условиях усиления конкуренции на рынке доставки еды команде сервиса «Всё.из.кафе» необходимо разработать стратегию роста. Для этого требуется проанализировать продукт и выявить наиболее перспективные направления развития.

**Данные:** 
- Логи сессий пользователей (действия, время, устройство, канал, город)
- Данные о заказах и покупках
- Данные о ресторанных партнёрах (выручка, стабильность)

---

## 🔧 Основные этапы работы

1. **Анализ пользовательского пути:**
   - Построение воронки от первого контакта до покупки.
   - Выявление проблемных этапов с наибольшей потерей пользователей.
   - Сегментация по каналам, городам и типам устройств.

2. **RFM-анализ:**
   - Сегментация пользователей по давности, частоте и сумме покупок.
   - Выявление ценных и невыгодных когорт.
   - Анализ распределения по каналам, городам и устройствам.

3. **ABC-XYZ-анализ ресторанных партнёров:**
   - Классификация ресторанов по прибыльности (ABC) и стабильности (XYZ).
   - Выявление самых ценных и проблемных партнёров.

---

## 📊 Ключевые выводы анализа

### 🚶 Пользовательский путь

**Ключевые проблемные зоны в воронке:**
| Этап | Проблема |
|------|----------|
| Главная → Регистрация | Потеря ~20% пользователей. Возможные причины: плохой дизайн, несоответствие рекламе, технические проблемы |
| Регистрация → Выбор ресторана | Серьёзная просадка после регистрации — пользователи не находят мотивации выбирать рестораны |
| Подтверждение телефона → Покупка | Критическая потеря на финальном этапе — возможны технические сбои или сложности с оформлением |

**По сегментам:**
- **Десктоп:** проблемы на этапе покупки (резкий скачок времени).
- **Мобильные:** проблемы на этапе ввода логина.
- **Саранск:** аномалии на этапе завершения покупки — требуется технический аудит.
- **Города с малым количеством пользователей** (Барнаул, Владивосток, Мурино) — более выраженные просадки.

---

### 📊 RFM-анализ

| Показатель | Значение |
|------------|----------|
| **Невыгодные пользователи** | ~50% (редкие покупки), из них 30% — маленькие суммы, 20% — очень давно |
| **Ценные когорты** (333, 233, 323, 332) | ~15% пользователей — часто покупают, средние/большие чеки |
| **Мобильные пользователи** | >60% невыгодны для компании |
| **Десктопные пользователи** | Более привлекательные, чем мобильные |

**По городам:**
- **Проблемные:** Барнаул, Мурино, Сочи — преобладание невыгодных пользователей.
- **Перспективные:** Владивосток, Саранск, Новосибирск — существенная доля выгодных пользователей.

## 💡 Рекомендации

### По пользовательскому пути
| Проблема | Решение |
|----------|---------|
| Главная → Регистрация | Провести A/B-тесты дизайна, проверить соответствие рекламе, исключить технические проблемы на десктопе |
| Регистрация → Выбор ресторана | Улучшить рекомендации ресторанов, добавить мотивацию (бонусы, персонализация) |
| Подтверждение телефона → Покупка | Технический аудит этапа оформления, проверка скорости и удобства |
| Аномалии в Саранске | Техническому отделу срочно изучить проблемы на этапе завершения покупки |

### По RFM и ABC-XYZ
| Направление | Решение |
|-------------|---------|
| Невыгодные пользователи | Провести анализ: пришли ли они по акции? Есть ли потенциал удержания? Снизить инвестиции в привлечение, если нет |
| Ценные когорты (333, 233, 323, 332) | Усилить программы лояльности, эксклюзивные предложения, ранний доступ, сбор обратной связи |
| Региональная стратегия | Изучить успешные практики Владивостока, Саранска, Новосибирска и масштабировать |
| Мобильные пользователи | Изучить, что делает десктопных более выгодными, и применить на мобильной версии |
| Прибыльные рестораны | Работать с ними, изучить причины нестабильности прибыли и разработать меры по стабилизации |
